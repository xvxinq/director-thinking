# 提示词与分镜模板

SKILL.md 讲原则，本文件给可直接抄的块。可裁剪，但**方括号内的必填项不要留空**。

---

## 一、单镜提示词块

```text
【主体】[年龄·性别·族裔] + [外貌：发型/脸型/一个特征] + [服装：颜色·材质·磨损程度]
【动作】[正在做的动词] + [身体姿态] + [手部在做什么]
【场景】[时间] + [天气] + [地点] + [两件可辨认的环境物件]
【镜头】[景别] + [机位角度] + [运镜] + [焦段感]
【光线】[光源方向] + [色温] + [对比度] + [一处实景光效]
【氛围】[用可拍的东西描述，禁止形容词堆叠]
【负向】[不要什么：文字/水印/多余手指/过度美颜/塑料感]
```

### 填写示例

```text
【主体】40 岁中国女性，齐耳短发有几根碎发翘起，深蓝色棉布外套，袖口磨白
【动作】蹲在门口擦一只旧搪瓷盆，反复擦同一块地方
【场景】清晨六点，阴天，南方老屋门前的水泥台阶，旁边停着一辆生锈的二八自行车
【镜头】中景偏低，固定机位，35mm，轻微手持晃动
【光线】阴天顶部散射光，冷调 5000K，低对比，门口木框上有一道暖黄灯泡反射
【氛围】像还没醒过来的一天
【负向】文字、水印、面部过度平滑、多余手指
```

## 二、结构模板

### 五段式短片（60–90 秒）

| 段落 | 时长 | 任务 | 落点 |
|---|---|---|---|
| 1 日常 | 0–8s | 建立「正常」 | 越正常，后面的破坏越有效 |
| 2 打破 | 8–15s | 日常被打断 | 冲突公式里的「巨大的阻碍」出现 |
| 3 升级 | 15–50s | 阻碍越来越强，人物被迫选择 | 每次升级都要改变人物一点 |
| 4 顶点之前 | 50–75s | **停住** | 克制：不给结果，给「要结果」的那一瞬 |
| 5 余韵 | 75–90s | 一个物件、一个空镜 | 让观众自己补完 |

> 第 4 段最容易写坏：90% 的人会在这里把情绪演满。往回收一格。

### 短剧单集（1–2 分钟）

时长不够做完整弧线，所以只做**一次转变**：

1. 前 10 秒：一个非常规的处境（信息错位 / 倒计时 / 反常细节，三选一）
2. 中段：主角按老办法应对 → 失败 → 被逼到必须改
3. 收尾：他做了一件「以前的他不会做」的事（哪怕很小：终于开口、终于转身、终于放手）
4. 钩子：把下一集的问题留在画外

**判断标准**：这一分钟结束后，人物和开始时是不是同一个人？如果完全一样，这集就只是在重复一个标签，观众不会追。

## 三、三关破局：给平淡场景加戏剧性

共同逻辑：**在平静里放入打破平静的力量。** 一句话就够，不要加设定说明书。

### 第一关 · 生存危机

- 原始：「一个男人坐在昏暗的房间里，平静地吃着一碗泡面。」
- 方法：**在平静的画面里，引入一个致命的威胁。**

| 版本 | 写法 | 效果 |
|---|---|---|
| 显性 | 「而他身后的衣柜里，一个手持匕首的黑影死死盯着他。」 | 制造**恐惧** |
| 隐性 | 「他吃着吃着，发现碗里有异物，拿出来一看，竟是他失踪十年的弟弟曾掉落的一颗乳牙。」 | 制造**不寒而栗** |

**隐性为什么更强**：它留下谜题——这弟弟现在怎么样了？谁抓了他？谁放的乳牙？为什么放？**观众的大脑会自动开始编故事。**

### 第二关 · 时间压力

- 原始：「一个女孩在图书馆看书。」
- 方法：加一个倒计时。

| 版本 | 写法 |
|---|---|
| 通知型 | 手机弹出：「图书馆外正在拉隔离带，30 秒后爆破拆除。」 |
| 封锁型 | 灯全灭，手机屏幕亮起：「你已被选中，留在原地。」（新闻里说有人质挟持，有人离开就会引爆） |
| 物理型 | 桌子底下，一个真的正在倒计时的定时炸弹 |

**公式：紧张 = 倒计时 + 不可逆。**
- 倒计时：还剩 3 分钟 / 灯一盏盏熄灭
- 不可逆：门已经锁了 / 车已经开走了

缺「不可逆」，倒计时只是着急；两者都在，才叫紧张。

参照：《大白鲨》《敦刻尔克》《雪国列车》——全部在用时间压力构建故事。

### 第三关 · 关系反转

- 原始：「一对情侣在咖啡厅聊天。」
- 方法：在平静表面下藏一个完全相反的力量，让预期落空。

| 版本 | 写法 |
|---|---|
| 荒诞型 | 服务员送上菜单，菜单上写着：「你已经去世了，您的遗产由对面这位继承。」 |
| 隐情型 | 男生跪下掏戒指，女生愣住——观众从她手里攥着的怀孕报告单看出，这次求婚对她是人生十字路口 |
| 身份型 | 一对便衣警察冲进来拿枪指着他们喊「别动，都被通缉了」——两人对视两三秒，同时站起来，铐住了对方的手腕 |

**心法**：你以为他是求婚，其实不是；你以为他们是情侣，也不止。

**铁律**：先让观众真心相信 A 会发生。**观众猜不到 A，B 就不成立。**

## 四、镜头词汇表【延伸补充】

> 原讲义只讲了「画面翻译成镜头」这一层，且明确反对「景别 = 情绪」的公式。下面是参数**词汇**，不是公式——用它来描述你的决定，不要用它来代替决定。

### 景别

| 景别 | 信息量 | 常用场景 |
|---|---|---|
| 大远景 | 环境与人的关系 | 开场、交代时代 |
| 全景 | 人物全身 + 空间 | 建立动作 |
| 中景 | 半身，手势可见 | 对话主用 |
| 近景 | 胸以上，表情为主 | 情绪转折 |
| 特写 | 单一细节 | 强调、揭示 |
| 大特写 | 眼睛、指节、物件局部 | 悬念、克制点 |

### 机位角度

| 角度 | 心理效果 |
|---|---|
| 平视 | 平等、客观 |
| 仰拍 | 压迫、崇高 |
| 俯拍 | 弱小、被审视 |
| 过肩 | 关系、对峙 |
| 主观 | 代入 |

### 运镜

| 运镜 | 何时用 |
|---|---|
| 固定 | 让观众自己看，最不打扰 |
| 推 | 逼近心理 |
| 拉 | 揭示环境、孤立人物 |
| 摇 | 转移注意、交代空间 |
| 跟 | 陪伴感、紧迫感 |
| 手持 | 不安、真实 |

### 时长经验值

- 建立镜头：2–4s
- 对话镜头：3–6s（随台词长度）
- 情绪停留：比你以为的多 1s
- **克制点：故意多停 1.5 倍**，让观众有时间补完

## 五、正反例改写

### 例 1 · 抽象 → 具体（最核心的一条）

| | 文本 |
|---|---|
| ✗ 差 | 沙漠里一个美女在微笑 |
| ✗ 结果 | 光效很好、有运镜、像标准广告片，**很容易被划走**，因为这种视频太多了 |
| ✓ 好 | 一个衣衫褴褛的女人在沙漠里找到一处水源，俯身要喝水时，水面的倒影里出现一把正刺向她的刀 |
| ✓ 结果 | 观众好奇后面到底发生了什么，**会坚持看到最后一秒** |

诊断：同样的工具、同样的模型。差别只在后者有你亲手放的钩子。

### 例 2 · 情绪戏

| | 文本 |
|---|---|
| ✗ 差 | 女人很伤心，她在雨中哭泣，情绪崩溃 |
| ✓ 好 | 雨里，她把伞收了。站在便利店门口，看手机屏幕上一条没发出去的消息，删掉，又打上，又删掉。玻璃门里有人在看她，她没抬头 |

诊断：差在「很伤心」「崩溃」是结论，不是画面；好在全是可拍的动作，情绪由观众自己得出。

### 例 3 · 冲突

| | 文本 |
|---|---|
| ✗ 差 | 他是一个好警察，罪犯很坏，他们打了一架 |
| ✓ 好 | 他抓了十年的人，这次抓到了，是他儿子的班主任。他得选：交上去，儿子班上没人敢管；放掉，队里都知道他放人 |

诊断：差在「好人 vs 坏人」；好在两种选择都合理——黑格尔级的冲突。

### 例 4 · 结尾

| | 文本 |
|---|---|
| ✗ 差 | 两人抱头痛哭，说「我们再也不分开了」，全片终 |
| ✓ 好 | 他把碗洗了，放进橱柜。橱柜里另一只碗已经收了。他站在那儿，手还搭在柜门上 |

诊断：差在演到顶点；好在停在顶点之前，观众自己接住「她走了」。

### 例 5 · 开场

| | 文本 |
|---|---|
| ✗ 差 | 早晨，阳光照进窗户，城市开始新的一天 |
| ✓ 好 | 他醒来，发现自己穿着昨天的鞋 |

诊断：差在流水账；好在第一个镜头就打破了日常，且留了谜题。

### 例 6 · 交代信息（台词 vs 一场戏）

| | 做法 |
|---|---|
| ✗ 差 | 台词：「我已经十岁了。」「我们已经十年没见了。」 |
| ✓ 好 | 设计一个只有相处十年才做得到的动作（自制滑雪板、能背出对方的口味、随手就知道药放在哪一格） |

诊断：靠台词交代等于广播剧。**让人物用嘴说出自己的处境，等于放弃这场戏。**

## 六、诊断模式输出格式

任务是「为什么这段不好看」时，按这个结构给：

```markdown
## 诊断
**病灶**：[一句话，指出最致命的一处]

## 逐项体检
| 项 | 判定 | 证据 |
|---|---|---|
| 可拍性 | ✗ | 通篇「悲伤」「震撼」，无一个可拍细节 |
| 镜头设计 | ✗ | 全片一个景别，无功能区分 |
| 结构 | △ | 镜头漂亮但连接无因果 |
| 情节 | ✗ | 主角经历三件事，但没有任何变化 |
| 冲突 | △ | 有对立，但反派明显无理，未达黑格尔级 |
| 悬念 | ✗ | 靠「故意不说」，非信息错位 |
| 麦高芬 | — | 无，故事容易散 |
| 克制 | ✗ | 结尾演满了 |

## 最小修改方案
1. [改哪里，怎么改，改完什么效果]
2. …

## 改写示范（任选一场）
[改前] → [改后]
```

只给一个「最小修改方案」就够，不要一次列十条——十条等于没建议。

### 常见断言（可直接用）

| 用户说 | 你可以答 |
|---|---|
| 「这段太平了」 | 缺的是打破日常的那一下。给一个「不能抬脚」的状态 |
| 「有 AI 味」 | 形容词太多，名词和动作太少；换成带磨损的具体物件 |
| 「提示词不生效」 | 先查剧本层：这句话本身能不能拍。再看提示词精度 |
| 「反转不够」 | A 没立住。先加一场确认戏把 A 钉死，B 才成立 |
| 「人物立不住」 | 他全程没变。给出起点、关键事件、终点三格 |
| 「一分钟太短做不了人物」 | 只做一次转变，不要做完整弧线 |
