# 拍摄实录与拉片案例库

这份文件里的前三个案例来自《倚天屠龙记》导演杜渊（参与《大明王朝1566》《大秦帝国》，执导 2019 版《倚天屠龙记》）的现场决策过程。它们是「把不能拍的翻译成能拍的」最完整的两条实操链，比任何原则都好用。

**读法**：卡住时不要读全文，直接搜关键词——转场、出场、关系、悬念、麦高芬、时间压力。

---

## 案例 A · 一个镜头让主角长大八年

**来源作品**：2019 版《倚天屠龙记》，张无忌从小演员换成成年演员。

### 问题

原著里张无忌是在第 16 章（练完九阳神功之后）长大的。但对电视剧来说：

- 成年张无忌是全剧男主角，**不可能第 14 集才出场**
- 长大之前的红梅山庄戏份，有很多跟朱九真的暧昧戏，不适合同一个小演员演

所以必须改时间点。改到哪儿？**只能改到有时空跨度的地方**——张无忌送杨不悔去杨逍坐忘峰的长途跋涉。利用这段艰险的旅途，让观众感受到他长大的过程。

> 这一步已经是在**改变原著小说的时空关系**了。导演的权力就在这里：时空在你手里。

### 四个前作的解法，都不满意

| 版本 | 做法 | 问题 |
|---|---|---|
| 1993 马景涛版 | 被杨逍关进地牢八年，镜头一转孩童变马景涛 | 剧本改动太大，离原著远，只能参考转场方式 |
| 2001 吴启华 TVB 版 | 按原著时间点，掉下悬崖练九阳神功，盘腿打坐旋转时渐变成吴启华 | 把转场交给当时很差的特效，太冒险，属于「偷鸡」 |
| 2003 苏有朋版 | 练完九阳神功，钻进河里一个网，再钻出来就是苏有朋 | 类似，仍靠技巧而非叙事 |
| 2009 邓超版 | 第 13 集才出现；抓着树藤荡秋千出场 | 出场最晚，且完全无法参考 |

**共同病灶**：要么把转变放在情节上，要么放在特效上。结果**只完成了「长大」，没有告诉观众这个孤儿是怎么艰难长大的。**

原著给人的感受是「历经磨难，终成大器」——这个意象一直留在导演脑子里，而这几版都没有。

### 解法

1. **找编剧改剧本**：在从坐忘峰返回中原的途中，安排一场四季更替，张无忌在冬天长大成人。
2. **导演做第二个选择：什么环境能承载这个剧本？**
   - 摄影棚？不行。
   - 横店的山里？不行。
   - 因为脑子里已经有「独行客」这个画面，所以知道**这场戏必须在广袤的西北大山**才能还原。
3. **实拍中的顿悟**：
   > 当我持续地拍小无忌艰难独行的这些镜头时，我突然明白了什么是可以省略的——具体的春夏秋冬转场其实可以省略。最重要的是能拍出张无忌的孤独感，以及这条归途的艰难，**这是必须强调的**。
4. **一个镜头解决八年**：找一座山顶，用航拍——小无忌独自走上山顶，回望来时路，此时已经是成年张无忌，含泪看向自己的来路。

### 为什么这个镜头成立

> 只有观众相信了作为孤儿的小张无忌必须独自面对这种艰难险阻，**一个镜头让他长大，观众也会接受的**。因为这个孩子吃的苦太多了，该长大了。

**这是全案最关键的一句。** 长镜头之所以能跳八年，不是镜头技巧高明，是前面已经把「艰难」累积够了。省略的合法性来自强调。

### 带来的代价（也是导演的本分）

这个方案要说服演员、说服制片方、说服全组爬到高山上，只为拍一个镜头。你必须在现场把**这个镜头的意义**告诉每一个主创，让演员带着热泪看着来路，用眼神告诉观众「我终于长大了」。

> 在成片剪出来之前，全组只有你一个人看到了那个画面。你要把这个信念传给每一个人。

AI 工作流里，这一条等价于：**把意图精确地传进提示词，而不是把一句模糊的话丢给模型。**

## 案例 B · 一场戏交代四件事

**来源作品**：2019 版《倚天屠龙记》，冰火岛上小张无忌的出场。

### 原著写了什么（第 7 章·谁送仙鹤来仙乡）

> 数年时光荏苒，三人在岛上相安无事。那孩子百病不生，长得甚是壮健。三人中，到此谢逊对他最为疼爱。有时孩子太过顽皮，张翠山和殷素素要加责罚，每次都是谢逊从中拦住。如此数次，孩子便视他作为靠山，逢到父母发怒，总搬到义父处求救。张氏夫妇往往是摇头苦笑，说孩子给大哥宠坏了。

### 关键信息与拍摄困境

原著传达的其实是三件事：**数年时间一晃而过**（婴儿已长大）、**孩子健壮**、**谢逊最宠他，父母管不住**。加上一层：这几个江湖中人，如今的关系已经和从前截然不同。

但按原文直接拍，**全都拍不出来**：

- 「弹指一挥间」拍不出来
- 「如何在宠溺中长大」拍不出来
- 「百病不生、长得壮健」拍不出来

### 编剧的第一次翻译，仍然不够

编剧把「时光荏苒」翻成「转眼无忌已是十岁」——**这依然拍不出来。**

> 你不能让台词说「他已经十岁了」。只靠台词交代人物，很偷懒，也不产生戏剧效果，跟广播剧似的，观众没有印象。

让人物用嘴说出自己的处境，等于放弃这场戏。

### 解法：在实景里找一个能证明时间的动作

剧组到了实拍地，导演跟当地哈萨克族人聊天，才知道那里是**全世界最大滑雪板的诞生地**。当地人踩着自制的滑雪板在雪原上追鹿：木板底上覆鹿皮毛（增加接触面积不下陷），一根撑杆（不是两根，两根太现代）——非常古朴。

于是设计：**小无忌踩着自制的滑雪板出场，跟父亲一起滑雪。**

一场戏，同时完成了四件事：

| 要交代的 | 这个动作怎么交代 |
|---|---|
| 十年岁月 | 能自制滑雪板、能在雪原上自如滑行 = 这家人在极寒之地已经生活得非常从容 |
| 孩子健壮 | 滑雪的身手就是体质证明 |
| 谢逊溺爱 | 现场临时加戏：金毛狮王**放下屠龙刀**，陪孩子去抓鱼 |
| 关系已变 | 杀人如麻、势当如命、为屠龙刀瞎了眼的人，如今觉得「这孩子比屠龙刀重要多了」 |

而且顺带埋了伏笔：正因为他视无忌如子，后来才执意要张翠山夫妇带孩子离开冰火岛。

> 原小说冰火岛的戏份非常少。我们用一场戏，完成了从文学到剧本、从剧本到画面的两次翻译。

### 可迁移的三条

1. **先问「这句话能不能拍」，再问「怎么拍」。** 不能拍就找替代动作，不要试图硬拍。
2. **替代动作要能承载多个信息。** 一个好的出场戏，抵得上一整集交代。
3. **现场找素材，不要在屋里编。** 滑雪板是当地人的真实生活，不是编剧想出来的——巴赞说的「指纹」，就是这种东西。

## 案例 C · 三分钟造一个宇宙

**来源作品**：《丧尸清道夫》（网络爆款 AI 短片，作者 Max Sher，成本约 3000 元）。放在这里是因为它示范了**短片如何用导演思维弥补时长**。

### 现象

提示词放出后，二创铺天盖地，视觉元素、机器人、鸵鸟、模型、算力都可复制，**没有一部出圈**。为什么？

因为它出圈靠的不是技术，是那「三分之一的导演思维」——作者生成了大量素材，最终只选了其中一小部分。

### 三个成功点

**1. 冲突（四层同时存在）**

| 层 | 冲突 |
|---|---|
| 形式与内容 | 画面是高对比的橙黄 + 亮蓝、美国西海岸风情，看着温暖鲜活；内容却是机器人清理丧尸 |
| 类型与角色 | 丧尸片本该惊悚，片里却是憨厚可爱的鸵鸟 + 顽皮深情的清道夫 |
| 场景与情绪 | 满屏丧尸视觉元素、开枪消灭丧尸，却营造了大量两人独处、爱意缠绵的画面 |
| **人与自己（最高级）** | 机器人本应只完成既定任务，却渴望陪伴和爱情 |

**2. 悬念**

开场就在营造「这个宇宙很奇怪」：这机器人是谁？为什么在这？为什么对一个塑料模特那么依恋？看到最后他回到太空基地，依然只有他一个——所以需要陪伴；那个模特可能是他偶像的复制品，也可能是别的。各种可能让人无限推演。

**3. 预期违背（三层）**
- 你以为他是清理丧尸的机器人 → 其实是有情有义的浪漫机器男孩
- 你以为这是机器人消灭僵尸的故事 → 其实是略带凄美的爱情故事
- 你以为他是在跟塑料女孩告别 → 其实把她带上了飞船（也可能每次回地球都会带一个同样的模特回去）

### 人物弧（三次变化）

按程序干活的工作状态 → 对塑料模特产生爱情依恋 → 违反程序把她带上飞船。

> 三分钟，人物完成了三次性格呈现变化，所以观众会脑补整个故事的来龙去脉。

### 结论

- 「很有戏」= 观众自己会脑补来龙去脉。
- 不是猎奇，不是数字奇观，是**给观众留下了感受和想象的空间**。
- 人物有发展空间 → 故事有衍生价值（马上有人想找他做游戏、做影视开发）；人物太单一 → 故事扁平、无法延伸。

## 拉片速查

### 人物弧

| 作品 | 本性（不变） | 起点 → 终点 |
|---|---|---|
| 《西游记》 | 嫉恶如仇、孤胆英雄 | 狂妄叛逆的妖王 → 有担当的护法者 |
| 《这个杀手不太冷》 | —（底色是冷漠下的温情） | 独来独往的杀人机器 → 为他人坦然赴死的保护者 |
| 《阿甘正传》 | 智力不足但善良纯粹、一根筋 | 自卑懵懂的弱势孩童 → 执着勇敢的实践者 → 温柔从容 |
| 《骆驼祥子》 | — | **向下**：纯良 → 堕落（弧线不一定向上） |
| 《丧尸清道夫》 | 机器人（程序） | 按程序 → 依恋 → 违反程序 |

### 冲突

| 类型 | 作品 | 冲突内核 |
|---|---|---|
| 人与人 | 警匪片、夺宝片 | 谁赢了（最浅） |
| 人与环境 | 灾难片、《雪国列车》 | 要是我在那会怎么办 |
| 人与自己 | 《大明王朝1566》海瑞 | 两个都应该做的事在心里打了一架 |
| 人与自己 + 环境 | 《狙击电话亭》 | 一个电话亭，不能出去 |
| 人与自己 + 制度 | 《棋士》 | 理智与欲望的撕扯 |
| 人与自己 + 社会 | 《搏击俱乐部》 | 分裂 |
| 伦理撕裂（真实） | 西德·玛丽安案 | 母亲当庭击毙虐杀女儿的凶手 |

### 悬念与反转

| 工具 | 作品 | 结构 |
|---|---|---|
| 信息错位 | 希区柯克「桌下炸弹」 | 观众知道炸弹，角色不知道，聊的每句废话都在加压 |
| 时间压力 | 《大白鲨》《敦刻尔克》《雪国列车》 | 倒计时 + 不可逆 |
| 预期违背 | 《丧尸清道夫》 | 三层反转，每层都先钉住 A |

### 克制

| 作品 | 顶点在哪 | 导演怎么处理 |
|---|---|---|
| 拉奥孔群雕 | 被蛇咬死的哀嚎 | 刻成叹息 |
| 《阿嬷的情书》 | 半生未见终于相见的瞬间 | 让男主失忆，只记得寄过咸猪肉 |
| 《走向共和》 | 晚清腐朽的正面控诉 | 拍李鸿章一丝不苟吃鱼，听见鹦鹉病了才放下筷子 |

### 麦高芬

| 作品 | 麦高芬 |
|---|---|
| 《疯狂的石头》 | 翡翠 |
| 《我不是药神》 | 印度仿制药 |
| 《倚天屠龙记》 | 倚天剑、屠龙刀 |
| 《007》系列 | 机密文件、病毒、核弹、密码 |

### 时间压力

| 作品 | 倒计时 | 不可逆 |
|---|---|---|
| 《大白鲨》 | 鲨鱼逼近的每一次浮标 | 已经下水了 |
| 《敦刻尔克》 | 潮水、燃油、敌机 | 船开走就回不来 |
| 《雪国列车》 | 车厢一节节推进 | 列车不能停 |
