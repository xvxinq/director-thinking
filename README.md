# 导演思维 Skill · 安装说明

把「AI 时代的导演思维」方法论固化成可执行指令的 Agent Skill。适用于任何支持 **Agent Skills** 规范的宿主，也支持只能粘贴单个文件的平台。

## 包里有什么

```
director-thinking/
├── SKILL.md                     # 主文件，agent 自动加载：工作流 / 六个工具 / 质量门
└── references/
    ├── methods.md               # 方法论深潜：为什么这么写（选择、四级翻译、人物弧、冲突、悬念、麦高芬、克制、巴赞）
    ├── cases.md                 # 拍摄实录 + 拉片案例库：倚天屠龙记两个完整决策链、丧尸清道夫拆解
    └── prompt-patterns.md       # 提示词模板、三关破局全例、镜头词汇表、正反例、诊断格式
director-thinking-单文件版.md    # 上面四份合并版，给不支持多文件的平台用
```

## 它能干什么

| 场景 | 用法 |
|---|---|
| 写分镜 / 镜头表 | 「把这个故事做成 60 秒分镜」 |
| 写 AI 视频提示词 | 「给这一镜写 Sora / 可灵 / 即梦提示词」 |
| 文案 → 画面 | 「把这段广告文案翻译成能拍的画面」 |
| 改稿 | 「这段为什么不抓人 / 有 AI 味？」 |
| 短剧单集 | 「这集一分钟，怎么写才有人物发展？」 |
| 构思 | 「我想拍一个外卖员的故事，帮我想」 |

## 安装

### Claude Code
```bash
mkdir -p ~/.claude/skills
cp -r director-thinking ~/.claude/skills/
```
或项目内：`.claude/skills/director-thinking/`

### Cursor
```bash
mkdir -p ~/.cursor/skills
cp -r director-thinking ~/.cursor/skills/
```
项目级：`.cursor/skills/director-thinking/`
（不要放进 `~/.cursor/skills-cursor/`，那是内置保留目录）

### DeepSeek Harness (DSH)
```bash
mkdir -p ~/.dsh/skills
cp -r director-thinking ~/.dsh/skills/
```

### Codex / 其他命令行 agent
放进宿主的 skills 目录，或直接引用 `SKILL.md` 路径，让它「始终遵守」。

### ChatGPT / 豆包 / Kimi / 网页版（无 skill 机制）
把 **`director-thinking-单文件版.md`** 整份粘贴进：
- 自定义指令（Custom Instructions）
- 或项目/知识库的规则文件
- 或对话开头（长对话建议放知识库）

### Coze / Dify / n8n 等编排平台
把单文件版作为 System Prompt 或知识库文档挂上去；references 里的案例可以单独做成检索库。

## 怎么验证装好了

发一句：

> 把这句话改成能拍的画面：一个女人很伤心地走在雨里。

期望行为：**先指出「悲伤」不是画面**，再给出带名词 + 动词 + 磨损细节的版本，并按景别/机位/运镜/时长/光线补齐镜头信息。

再发一句：

> 这个分镜好平淡，怎么办？

期望行为：指出缺的是「打破日常」，从三关（生存危机 / 时间压力 / 关系反转）里选一种，给出一句可直接加进去的话。

如果它直接开始写漂亮句子，说明 skill 没被加载。

## 设计说明

- **主文件控篇幅**：SKILL.md 只放「必须执行的规则」，原理解释全部推给 references，避免占用上下文。
- **无脚本依赖**：纯 Markdown，不需要 Python / Node，任何宿主都能跑。
- **反公式**：明确反对「景别 = 情绪」的万能公式——这类教程正是它要治的病。镜头参数只作词汇表提供。
- **可裁剪**：只做 AIGC 提示词的话，删掉分镜表与剧本段落，保留工具 1/2/4/6 与三关破局即可。
- **可改写**：所有规则都是判断启发式，不是教条。团队有自己的标准时，直接改 SKILL.md 对应条目。

## 内容来源

1. 杜渊（独眼导演）《AI 时代的导演思维》实验编程社群分享会，约 103 分钟视频及文字稿。杜渊 2003 年毕业于北京广播学院（后中国传媒大学），从业 20 余年，参与《大明王朝1566》（做张黎的执行导演一年）、《大秦帝国之裂变》，执导 2019 版《倚天屠龙记》《玉骨遥》《锦月如歌》等。
2. 同课题的 19 页课程幻灯片讲义。

两份来源的核心命题一致：**选择、四级翻译、情节即性格发展、克制的表达、冲突与黑格尔悲剧观、悬念与预期违背、麦高芬、巴赞的「指纹」、一秒破局三关。**

文中标注 **【延伸补充】** 的部分为整理者补充，非原作者内容：镜头参数词汇表、部分改写正反例、五段式与短剧单集结构模板。
